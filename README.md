# 🎮 2D Tennis Game (C++ & SFML)

A simple 2D Tennis (Pong-style) game developed using **C++** and the **SFML (Simple and Fast Multimedia Library)**.
This project demonstrates core concepts of game development including real-time rendering, collision detection, and user input handling.

---

## 📌 Project Overview

This project was developed as part of an academic course to gain hands-on experience in game programming.

The game features:

* Two-player gameplay
* Paddle control via keyboard
* Ball physics and collision detection
* Real-time score tracking

According to the project report, the system is designed using layered architecture including input handling, game logic, and rendering .

---

## 🛠️ Technologies Used

* **Language:** C++
* **Graphics Library:** SFML 3.0
* **IDE:** Visual Studio Code
* **Concepts:** Object-Oriented Programming, Game Loop, Event Handling

---

## 🎮 Gameplay

* Player 1 controls paddle using **W / S keys**
* Player 2 controls paddle using **Up / Down arrow keys**
* The ball bounces between paddles and walls
* If a player misses the ball, the opponent scores
* First player to reach the score limit wins

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/IMRAN-8/First-Project.git
cd First-Project
```

### 2. Install SFML

Download from: https://www.sfml-dev.org/

### 3. Compile the code

```bash
g++ Game_code.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system
```

### 4. Run the game

```bash
./game
```
